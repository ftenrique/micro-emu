# ADR 0001: prototipo personal con firma de prueba

- Estado: Aceptada para el spike
- Fecha: 2026-07-29

## Decisión

La primera prueba VHF será un prototipo local con firma de prueba. No se
plantea distribución ni firma de producción hasta confirmar que ChatGPT
reconoce el dispositivo.

## Motivo

La Fase 2 es una puerta de viabilidad. Invertir en distribución antes de
superarla no reduce ningún riesgo técnico del reconocimiento.

## Consecuencias

- La instalación futura requerirá una máquina de prueba y reinicio.
- No se publicará un instalador de usuario final en esta etapa.
- Toda modificación de seguridad de arranque se documentará y será reversible.
